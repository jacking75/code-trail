# 첫 분석과 공유

언어 서버를 준비하기 전에는 저장소에 포함된 예제부터 읽을 수 있다.

```powershell
npm run build
node packages/cli/dist/main.js --read-share examples/first-review.ctshare.json
```

브라우저가 열리면 `분석 기록`에서 목표, 열린 질문, 안내 순서를 확인한다. 이 실행은
임시 디렉터리의 읽기 전용 복사본만 사용하며 예제 파일이나 다른 프로젝트를 바꾸지 않는다.

자기 프로젝트에서는 다음 순서로 첫 자료를 만든다.

1. `npm run start -- <프로젝트 경로>`로 연다.
2. 파일을 고르고 함수 안에서 `Ctrl+Alt+T`를 눌러 첫 루트를 만든다.
3. `분석 기록` 탭에서 새 분석을 만들고 트레일·노드·선택한 코드 범위에 기록한다.
4. `공유 내용 확인`에서 코드 포함 여부와 건수를 확인한다.
5. 공유 묶음, Markdown, 정적 HTML 중 수신자 환경에 맞는 형식을 내려받는다.

위치가 바뀐 기록은 `위치 다시 확인`으로 검사한다. `확인함`이었던 범위가 바뀌면
`재검토 필요`로 내려가며, 같은 본문 후보가 여러 곳이면 자동으로 하나를 고르지 않는다.
