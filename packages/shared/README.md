# @code-trail/shared

Domain types, protocol schemas (Zod), and the Markdown/share formats used by the server and the browser.

This is an internal component of the [`code-trail`](https://github.com/jacking75/code-trail) CLI. Do not install it directly;
run `npm install -g code-trail` instead.

코드 트레일의 도메인 타입, 명령·이벤트 프로토콜 스키마, 공유 형식이다. 파일 시스템·네트워크·DOM 에 의존하지 않는다.
