# @code-trail/server

The local server: trail store, language server (LSP) client, security checks, and the read-only HTTP/WebSocket API.

This is an internal component of the [`code-trail`](https://github.com/jacking75/code-trail) CLI. Do not install it directly;
run `npm install -g code-trail` instead.

트레일 정본, 언어 서버 클라이언트, 보안 검사, 읽기 전용 API 를 가진 로컬 서버다.
